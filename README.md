# Muon Imaging for Study Volcanoes: A PRISMA Systematic Review

## General Information

- **Article Title:** [Muon Imaging and its Application to the Study of Volcanoes: A PRISMA Systematic Review]
- **Journal:** Frontiers in Earth Science
- **Authors:** [Elizondo-Blanco, Daniel; Paniagua-Orozco, Luis; Gutiérrez-Calderon, Luis; Jiménez-Moya, Esteban and Arguedas-Cuendis, Sergio]
- **Corresponding Author:** [Elizondo-Blanco, Daniel: eelizondob@uned.ac.cr]

## Description

This repository contains supplementary materials supporting the findings of the manuscript, including figures, Python scripts, and CSV datasets used to generate the figures and perform the corresponding analyses.

## Structure

- `/materials`: Contains the figures, Python scripts, and CSV datasets used in the study.

## Data Availability

The supplementary materials associated with this study are publicly available in this GitHub repository.
